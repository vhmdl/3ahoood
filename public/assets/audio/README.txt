HOW TO CHANGE THE MUSIC (no settings inside the site)

1. Get any mp3 you like (a song, a voice note, anything).
2. Rename it to exactly:  ambient.mp3
3. Put it in this folder:  public/assets/audio/ambient.mp3
   (replace the old file if one is already there)

That's it. The music starts only after she presses "START THE JOURNEY"
(browsers block sound before a click) and then loops for the whole story.

Optional extra sounds, same folder, same idea:
  stone-activate.mp3    - plays when a stone is touched
  stone-transition.mp3  - plays during the stone animation
  final.mp3             - plays on the final birthday scene

If ambient.mp3 is missing, the site plays a soft synthesized space pad
instead, so it is never silent.
